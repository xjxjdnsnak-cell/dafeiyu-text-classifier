## 灰区不对称披露

## 结论（按约定区分事实 / 推断 / 未知）

**事实（直接测量）**：

1. B 未达到任何一条验收标准：普通昵称召回 35.71% 对 A 73.21%（**−37.6pp，严重回退**）；整体召回 48.90% 对 81.88%（−33pp）；误拦率 0.995% 在预算内但召回崩溃。
2. sfx 特征仅 19 个唯一值（8 种特征 × 分桶），每行 5 个，在**每一行**都出现——但去除 sfx 后逐行分数完全不变（stripping 测试），说明 sfx token 的训练后权重近零。
3. 尽管权重近零，训练时的存在仍然导致了模型回退——问题出在**训练动力学**而非特征预测力。
4. 模型体积几乎不变（5,609 KiB 对 5,476 KiB）——sfx 只有 19 个唯一值，不像字符 N-gram 那样导致体积爆炸。
5. 逐条差异：A 正确而 B 漏判 315 行，A 漏判而 B 正确 **0 行**——B 没有发现任何 A 遗漏的 AI 评论。

**推断（有证据支持）**：

- **在 fastText 的线性架构中，追加任何与内容特征高度冗余的结构特征都会破坏训练**。sfx 特征编码的是 txt 特征已隐含的结构信息（句子数、连接词等可从文本推出），它们在线性模型中没有独立信息增量。
- 机制：训练时 sfx token 的存在改变了 hidden state 的组成，content token 的 embedding 必须在"有 sfx 偏移"的条件下重新学习——30 epoch 后收敛到的解比无 sfx 时更差。这不是"sfx 是坏特征"的问题，而是"任何高频冗余 token 加入 fastText 都会破坏 content embedding 学习"的架构限制。

**未知**：

- 更换架构（如两层 MLP 或 attention）是否能让结构特征产生正收益——超出 fastText 范围。
- 句式结构信息本身是否具有超越 txt 特征的预测力——需要不同的模型架构来验证。

**最终判定**：普通昵称召回严重回退（−37.6pp）→ **保留 v8，句式结构特征路线关闭**。

**至此，正文模型所有低成本改进方向已全部实验闭环并否定**：

| 方向 | 实验 | 结果 |
|---|---|---|
| 负类降权 0.5 | neg-weight-ablation | 无收益 |
| Bagging PU | pu-experiment | 全面劣于 v8 |
| 历史负类追加 | historical-negative-ablation B | 主指标回退 |
| 历史负类等量替换 | negative-replacement-ablation D | 两项停止条件均失败 |
| 跨词字符 N-gram | char-ngram-ablation B | 模型 19 倍，召回 −7pp |
| 句式结构特征 | sentence-structure-ablation B | 召回 −33pp |

v8 的 73.21% 普通昵称召回 @1% FPR 是在当前数据和架构下的上限。进一步提升需要：更多高质量标注数据（dsh 社区真人标注）、或更换模型架构。这两者都需要新资源投入。
