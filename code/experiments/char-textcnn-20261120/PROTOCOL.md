# 字符 TextCNN 与冻结 fastText 的同批对照

基线为提交 7acb8c5 的遮蔽版 v9，原权重和阈值 0.9387965748548248。复用 v8 的 processed/train.csv、validation.csv、test.csv 和 manifest 哈希。训练集与两个评估集按原有视频、UID 和正文隔离。已有测试集属于历史留出集。

- 使用相同训练行、标签及每行一次的权重。照 v9 的训练历史，两者训练输入均为原文，推理时先检查纯提及，再在原始正文中将被提及的昵称替换为 `@某人`。沿用相同归一化和 4,096 码点上限。昵称仅用于结果分组。
- 一个字符级模型配置。按训练集构建字符词表，保留至少出现两次的字符。32 维字符嵌入，宽度 1、2、3、5 各 32 个卷积核，ReLU、按有效位置全局最大池化、dropout 0.2 和单个线性输出。短于卷积核的文本保留一个补零窗口。
- 固定 10 轮、批大小 128、AdamW 学习率 0.002、权重衰减 0.01、未加权二元交叉熵。种子 17、37、73 是同一实验的重复，全部报告。预选种子 17 用于手机计时，无早停或超参选择。
- 每个种子仅在验证集选阈值。以冻结 v9 在该集触发的规则负类条数为上限，沿用项目的阈值选择器。冻结所有权重和阈值再读留出测试行。分别报告实际负类触发数、全体正类、原文 1–20 个 Unicode 码点的正类、普通昵称正类及两者相交子集。
- 补充描述性排序指标：在测试集上，各模型分别取严格高于第 K+1 高负类分数的正类，K 为冻结 v9 测试集的实际负类触发数。此指标只比较相同负类开销下的排序，不用来更新工作点。
- 继续投入的条件为三个种子的冻结测试工作点均提高短评和普通昵称召回，且负类触发数不超过 v9。并报告同真机的单条推理延迟、中位数和 p95，供判断部署成本。原文到分数计时不含首次加载和界面渲染。手机输入为验证集前 100 条，不按模型分数筛选。若无重复收益，停止该路线。
- 规则标签只衡量规则一致性。此次不使用无独立标签的 884 条来估计准确率。
