# 点名提问与请求的学习实验

训练一个中文 TinyBERT 判断被 @ 的人是否被直接提问或被要求做事。模型只读去掉开头称呼后的正文。用于适用范围筛选的正则只识别点名位置；请求动词和句式由模型学习。此次候选仅离线运行。

## 训练和比较

从历史参考语料、历史视频评论和旧训练集抽取 203 条评论。训练采样富集了疑问和祈使表达，并混入随机正文。实验者在只看去名正文时标记请求、非请求或不确定，包括引用别人的问题、分享体验等反例。两批对照视频均在训练集之外。训练用 58 条请求和 108 条非请求，来自 50 个视频、163 个账号。37 条难判的评论未参与拟合。训练和对照数据按视频、账号、归一化全文和去名称呼后的归一化正文核对，四项交集均为零。

模型从 huawei-noah/TinyBERT_4L_zh 的通用中文权重开始，取最后一层有效位置的均值，训练二分类线性层及编码器。固定随机种子 17，AdamW 学习率 0.00003，6 轮，批量上限 16，一次训练。只对开头有一个可分辨的 @ 称呼、剩余正文为 1 至 64 个 Unicode 码点且不含其他 @ 的评论评分。得分达到预先固定的 0.80 时记为请求。未针对对照结果调整阈值。

在同一批评论上，把冻结的仅推理遮名 v9 结果与两种放行策略分别组合。原策略来自研究仓库提交 `3f218c7`。两种策略各自独立与 v9 组合；v9 阈值固定为 `0.9387965748548248`。

## 第二批的意图判别

466 条中有 78 条在意图模型处理范围内。实验者对这 78 条逐条标注意图，标注时只展示乱序的去名正文。此前已讨论过其中若干例子。作者风格盲评与这次意图标注分别统计。意图由单名 AI 实验者判读，7 条有歧义的评论单列。

| 统计对象 | 旧规则认出请求 | 学习模型认出请求 | 旧规则把非请求判为请求 | 学习模型把非请求判为请求 |
| --- | ---: | ---: | ---: | ---: |
| 按评论 | 7/23 | 17/23 | 0/48 | 3/48 |
| 去名正文相同的只计一次 | 6/20 | 14/20 | 0/48 | 3/48 |

学习模型覆盖旧规则在第二批认出的全部 7 条，额外认出 10 条明确请求。另有 1 条意图有歧义的评论被学习模型认成请求。3 条明确误识别涉及一个裸链接、一句讨论广告的陈述和一句表示认同的话。

## 本地运行

本次使用 PyTorch 2.11、Transformers 5.2、safetensors、pandas 和 NumPy。训练 CSV 使用 `text,intent`，意图标签为 0 或 1；评分 CSV 只需 `text`。预训练目录需要 `config.json`、`vocab.txt` 和 `model.safetensors`。

```sh
python pilot.py fit train.csv pretrained_dir intent_checkpoint
python pilot.py score comments.csv intent_checkpoint scored.csv
```
