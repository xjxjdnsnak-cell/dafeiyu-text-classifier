# 点名称呼与中文短评风格检测的独立先导评测

本实验测量点名放行策略对最终屏蔽决定的影响。主任务的参照是人类对可见文本风格的独立判断。意图标签描述发言者是否在向对方提问或请求行动。推广标签描述评论中可见的推广表达。三项分别标注，作者身份和实际生成过程仍需另有证据。

## 抽样与隔离

[冻结方案](protocol.json) 在读取此次评论前写入本地。候选视频来自 11 月 20 日留存的搜索结果，含 AI／插件相关的六组关键词和生活、运动、摄影等六组普通话题关键词。每个检索词优先选择两个历史数据中未见的视频，按公开评论数降序、BV 号打破平局，保证本轮视频和上传者互异。同话题不足时从同一组的其余候选补齐，实际检索词和原配额保存在私有选片清单。每个大组交替把两个名次分到自然样本或诊断样本。

每个视频读取时间序前两页，每页最多 20 条一级评论，包含接口随页返回的楼中楼。保留冻结时间窗内合格的全部评论 ID。先剔除历史账号、全文、去名正文和缺乏可比较文本的记录。再排除与自然样本重叠的诊断记录。同一组内部的相同表达保留其自然出现次数。可估计的范围是这些检索词、视频、页次和去重条件下的评论。视频搜索排名、内联回复和历史去重均影响样本构成。

历史索引复用原采集器的 sqlite 数据、分类器语料与四维来源追踪，并加入两批旧视频的可见评论、意图训练及开发材料、两次重训的训练清单和评分文件。按可追溯的 BV／aid、账号及关联 UID、归一化全文、去名称呼后的归一化正文排除。文本使用 NFKC、casefold 和标点空白归一，同时跨全文与去名形式比对。另核对冻结预处理的可见前缀以及已知评论 ID。历史材料中缺失的来源标识无法从交集计数中恢复。预训练基础模型的原始语料也不在此索引中。

盲评纳入所有合格自然评论，以及另 12 个视频中同时满足“冻结 v9 会拦”和“进入意图模型评分范围”的全部评论。两组在盲评表内混排。两名人类各自独立完成一份，看到去名称呼后的正文、独立编号和三项判断，不提供预测、分数、视频、作者昵称或样本组别。

## 模型与判定

- 主比较采用相同的遮名 v9 作为底层分类器。先分别运行无放行、PR #6 的旧规则和 PR #7 的 TinyBERT 放行策略。前两者复用原预测入口，学习策略复用冻结评分脚本和阈值 0.80。
- 辅助比较包含 v8、原始 v9、历史负类降权的 v8.1／v9.1、训练也遮名的候选。原始 v9 和历史降权 v9.1 均使用未经推理遮名的特征，与推理遮名候选分列。对训练遮名的候选，分别保留裸模型决定及原候选附加固定句式保护后的决定。各系统均保留自己的历史阈值。
- 中文 RoBERTa 使用 hfl/chinese-roberta-wwm-ext 的固定版本，输入原正文，以项目历史弱标签拟合分类头和编码器。固定一轮、单种子、最大 128 tokens，在旧验证集的 1% 误拦预算下选召回最高的阈值。训练文件与权重哈希写入私有清单。
- Qwen2.5-7B-Instruct 采用固定的本地量化模型，通过本机 Ollama 零样本判断去名称呼后的文本风格。使用二选一结构化输出、固定提示、温度 0、种子 17。模型结果仅作为参照系统。
- 研究使用 AI 助手起草的 12 组合成探针。每组交叉组合两种称呼和请求／陈述两种表达，共 48 个输入。探针的预期标签限于意图和改名一致性，按 12 个句组汇报。这批探针供行为诊断，未经独立人工校验，不参与训练、自然样本指标或作者来源标注。

## 人工回收与统计

两份工作簿保留独立编号。程序逐条核验编号、正文、完整性及允许值。风格、意图、推广分别计算裁决前混淆矩阵、原始一致率、Cohen κ 和两人的不确定比例，同时按样本组别单列。裁决者只处理有分歧的字段，可保留“不确定”；裁决表使用独立编号，不含模型输出。

主结果在自然样本及其普通昵称短评子集（原作者昵称不含历史模式、原正文 1 至 20 码点）分别报告。列出模型实际误拦数、检出数、每千条真人风格评论误拦数、AI 风格召回、精确率和 F1。连续输出额外报告平均精确率（AP，按并列分数共同入阈计算）。无法判定的风格计数单列。相对于旧规则的误拦减少量及召回差使用同一条评论的配对结果，在两类视频池内按视频有放回抽样 5,000 次，给出区间和有效重复次数。视频数少或零分歧时，区间只作描述。诊断组只报告条件计数。主方案预设后续确认实验最多接受 2 个百分点的绝对召回损失，先导批不作上线判定。

## 运行

在研究机的现有归档结构下运行。以下工作目录为项目所在的 BiliPai 工作区，脚本目录为当前研究 worktree 下的 `analysis/prospective_style`。将 `$p` 指向脚本目录，`$private` 指向研究仓库外的独立私有目录。历史采样档案、PR #4／#6 worktree、历史权重与语料属于本地依赖，只有仓库代码时不能复原真实评论。原始快照和选片清单缺失时重新联网会得到不同的抽样框。

```powershell
& ./fasttext-classifier/.venv/Scripts/python.exe "$p/collect.py" . $private
python "$p/roberta.py" fit . $private
python "$p/roberta.py" score . $private
python "$p/qwen.py" $private
& ./fasttext-classifier/.venv/Scripts/python.exe "$p/score.py" . $private (Get-Command python).Source
& ./fasttext-classifier/.venv/Scripts/python.exe "$p/audit.py" . $private
python "$p/review.py" packet $private
python "$p/web_packet.py" $private $output
node "$p/workbooks.mjs" $private $output
python "$p/review.py" evaluate $private --a $reviewA --b $reviewB
python "$p/review.py" evaluate $private --a $reviewA --b $reviewB --adjudicated $decisions
python -m unittest discover -s $p -p test_review.py
```

离线网页和 Excel 共用同一份盲评编号与正文。标注者只打开自己的 HTML，在浏览器中逐条选择三项判断。进度保存在当前浏览器，可导出 JSON 备份并在同一标注者的页面恢复。全部填完后导出的 JSON 可直接作为 evaluate 的 A 或 B 输入，支持与 Excel 混合回收。

采集与 fastText 复用项目环境。RoBERTa、TinyBERT 使用本机 PyTorch 和 Transformers。将固定版本的原始配置、词表、权重和带 LFS SHA256 的 Hugging Face 模型 API 元数据 source.json 存放于私有目录 roberta-source 下，fit 会核验原始权重。工作簿生成需能解析 @oai/artifact-tool 的 Node 环境，回读用 openpyxl。已发出的工作簿拒绝覆盖，返回的工作簿保留原样。首次 evaluate 产生私有分歧表，裁决后传入完成的副本。真实评论、账号、预测明细、盲评表及模型权重均在本地。公开研究仓库仅包含脚本、方案、合成探针和汇总。
