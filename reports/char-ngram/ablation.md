生成：2026-11-14T09:42:53+00:00。B 保留全部 txt_ 词特征与词 bigram，仅在行尾追加规范化正文（max_text_chars 截断）的连续字符 2/3/4-gram（前缀 chx_，跨 jieba 边界）。参数、词典、预处理、种子与 v8 完全一致；阈值：A 冻结，B 在 v8 验证集按冻结协议选择。历史参考基准未使用。

## 现有实现检查（实验前提）

- `minn=2, maxn=4` 的实际作用范围：fastText 子词只作用于**单个 token 内部**——本管线 token 为 `txt_词` 整串（含 `txt_` 前缀），子词含 `<`/`>` 边界标记，**从不跨 `txt_词1 txt_词2` 边界**（已用 v8 模型 get_subwords 实证，见 ablation.json）。
- 每 token 的 9 个子词是所有 token 共享的 `txt_` 前缀样板（`<t`、`<tx`、`<txt`、`tx`、`txt`、`txt_`、`xt`、`xt_`）——信息量集中在词内片段。
- 因此 v8 中不存在跨分词边界的字符 N-gram；跨词模式只靠 wordNgrams=2 的整词对。B 的增量是真实的特征空间扩展，不是重复实现。

## 结论（按约定区分事实 / 推断 / 未知）

**事实（直接测量）**：

1. B 在全部四条验收标准上失败：普通昵称召回 66.07% 对 A 73.21%（−7.1pp，66 行被换成了 23 行——净损失 43 行）；误拦率同为 1%（预算内）；H 证据触发持平（0.48%）；模型体积 **104,951 KiB（19 倍）**、加载 980 ms（27 倍）。
2. 特征空间：唯一特征从 20,558 个暴涨到 681,645 个（chx 661,087 个），训练文件 2.9 MB → 20.0 MB。在 bucket=20000 的共享哈希空间里，66 万个新特征与原有词语/子词/词 bigram 特征发生严重碰撞。
3. B 的验证集最优阈值低至 2.5e-05——分数分布被字符特征完全重塑，与 A 不可直接比较。
4. 长度分组全面回退：1–20 字 23.5%（A 48.5%）、21–60 字 74.7%（A 79.0%）、61+ 字 90.6%（A 91.6%）。
5. 逐条差异：A 正确而 B 漏判 66 行，A 漏判而 B 正确仅 23 行——净损失 43 行正类。

**推断（有证据支持）**：

- 在 bucket=20000 的固定哈希预算下，66 万个显式字符特征把词语/子词/词 bigram 特征挤出哈希空间（碰撞），破坏了 v8 已学到的表示——这是召回全面回退的最可能机制。
- 即便不受碰撞影响，字符 N-gram 特征的高基数（66 万唯一值）与 fastText 线性模型的容量也不匹配：多数 chx 特征在整个训练集中只出现一两次，学到的权重接近噪声。

**未知**：

- 增大 bucket、限制 chx 只取高频片段、或按文档频率过滤后再加入，能否让字符特征产生正收益——本轮按"不进行开放式超参数搜索"的约束未验证。
- 字符特征在更大模型（如 TinyBERT 类架构）中的价值——不在 fastText 范围内。

**最终判定**：四条验收标准全部失败 → **保留 v8，停止本轮实验**。跨词字符 N-gram 在当前 bucket 预算与线性模型容量下不是可行方向；若未来要利用字符级模式，需要更换支持更大特征空间或显式特征选择的架构，那已经超出 fastText 的范围。

## 失败原因修正（2026-11-14 外部复盘）

原报告把"bucket 碰撞挤出既有特征"列为最可能机制——**降级为合理怀疑、尚未证明**。修正后的归因如下。

### 三个同时发生的表示改变（均为可测量事实）

1. **词 token 稀释**：每行特征 token 从 25.56 → 133.27（txt 占比 100% → 18.2%）——原始词语特征对 fastText 隐藏层（token 求和池化）的贡献被稀释约 **5.5 倍**。
2. **wordNgrams=2 作用于 chx token**：每行 bigram 从 ~24.6 → ~139（5.7 倍）——新增大量 chx–chx 组合与 txt–chx 边界组合（fastText 对行内相邻 token 做哈希，此为架构行为，非可选）。
3. **词表膨胀**：唯一特征 20,558 → 681,645（chx token 成为独立词条、各占 embedding 行），模型 19 倍。

### 两个候选机制（均未证明为主因）

- **哈希碰撞**：66 万特征进入 20k bucket——合理怀疑；
- **表示组成改变**（稀释 + bigram 泛滥）——对短评崩溃（48.53% → 23.53%）可能更具解释力。

### B 阈值 2.5e-05 的正确读法

只说明分数分布被字符特征重塑（校准失效），**不能单独证明表示已失效，也不能证明模型仍有救**——中性证据。

### 新发现的实现缺陷（自查披露）

chx N-gram 按字符窗口提取时**未跳过含空格的窗口**：跨越空格的 n-gram 生成了含空格的断裂 token（重新分词后变成无前缀碎片）。量级：B 特征流中 87,812 个 token（6.8%）为该类碎片。这一缺陷给 B 增加了额外噪声——意味着 **B 的结果可能低估了"正确实现的字符增强"**；但原始差距（普通昵称召回 −7.1pp）较大，按既定预算不重跑修正版本。

### 对原结论的修正

原表述"字符 N-gram 在当前 bucket 预算与线性模型容量下不是可行方向"改为：**"在 bucket=20000、词表不设限、以词 token 形式追加、且含空格窗口缺陷的本次实现下无收益"**。不代表字符级模式对该任务无价值，也不代表 fastText 的低成本改进空间已耗尽。
