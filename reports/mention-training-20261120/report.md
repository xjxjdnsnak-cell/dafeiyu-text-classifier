# 遮蔽正文中被叫到的昵称后重训 v9

重训候选在历史测试集上检出了 423/697 条规则正类，原 v8 检出 366 条。在用户判别并按视频留出的 21 条短评上，四版都漏掉了唯一一条人工判 AI 的评论。20 条人工判真人的评论中，重训版错拦 4 条，原 v8 错拦 6 条，只在推理时遮住昵称的 v9 错拦 2 条。维持 v8 发布状态。

## 数据和改动

训练前备份并逐文件核对了 99 个原文件，含原始划分、原训练语料、用户复核及采集记录、原模型和阈值。备份 SHA256 为 `7df6eed90e2b70f048d64a4178b7c79bb443e09e89d83351fecb53c018532a14`。训练完成后再次验证了原件和备份。

候选沿用 v9 的 fastText 参数、冻结词典和句式特征。训练和预测都复用原有昵称遮蔽函数，先判纯提及，再将正文中被 @ 的名字替换成“@某人”。另外，正文仅为“快来学学”的招呼直接放行，可带前置 @ 称呼和句末标点。其他有正文的短句照常评分。保留独立的模型分数及最终放行原因。

原训练集全部 12,961 行保留。50 条开发短评中，2 条遮蔽后的输入与受保护的评估输入相同，另有 2 条与已加入的复核行重复。实际加入 46 条人工判别（3 条 AI、43 条真人），每条一次，最终共 13,007 行。21 条留出短评来自另外两个视频，训练排除了相同账号以及遮蔽后相同的输入。

候选训练一次，在原验证集 2,764 行上按 1% 规则负类触发预算选阈值，然后写盘冻结并评估。阈值为 `0.8800823463417595`，模型 SHA256 为 `4b4c8fdb38aa86b6bc8dce88080accb975664e1b253e3ea6d5f290f00338ecc9`。原 v8 使用阈值 `0.9700783414714084`，原 v9 和只在推理时遮名字的版本均使用 `0.9387965748548248`。

## 使用

解压离线模型包，在包根目录运行下面的预测命令。Python 依赖见 `code/requirements.txt`。训练命令用于源码仓库，需要含原始数据和复核文件的项目工作区。

```text
python code/predict_mention_trained.py --model-dir candidate --text "@小鱼 快来学学。"
python code/experiments/mention-training-20261120/run.py --workspace <私有数据工作区> --output <新输出目录>
```

四版逐条预测保存在本地实验输出的 `held_out-scores.csv`、`development-scores.csv`、`validation-scores.csv` 和 `test-scores.csv`，公开报告仅附汇总和冻结参数。
